# categories/{categoryId}

Admin-managed career paths used by public discovery and Employer job forms.

```json
{
  "name": "Technology",
  "description": "Software, data, IT, and engineering roles.",
  "iconName": "memory",
  "isActive": true,
  "sortOrder": 1,
  "updatedAt": "timestamp"
}
```

Public users may read active categories. Admins manage all category records.
