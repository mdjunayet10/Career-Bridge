# Bundled UI typography

Sora is bundled locally so first launch, admin login and offline work do not need a Google Fonts HTTP request. The original family and weights (400, 500, 600, 700, 800) are retained.

Source: https://github.com/google/fonts/tree/main/ofl/sora
License: OFL.txt (SIL Open Font License).

The static weight files were generated from the official variable TTF using fontTools.varLib.instancer. The original input is retained for reproducibility. This changes font delivery, not the intended design.
